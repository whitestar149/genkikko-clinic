# げんきっこクリニック WEB予約システム

ポートフォリオ用に作成した、架空の小児科クリニック向けWEB予約デモアプリです。

## 主な機能
- 一般診療 / 予防接種 / 乳幼児健診の予約
- 患者情報・症状入力
- 予約内容確認
- 予約番号発行
- 予約確認 / キャンセル
- スタッフ向け予約管理画面
- ステータス変更
- 予約件数ダッシュボード
- localStorageによるブラウザ内データ保存
- スマホ対応レスポンシブデザイン

## GitHub Pages で公開する方法
1. index.html / style.css / script.js を同じリポジトリにアップロード
2. GitHub の Settings → Pages
3. Branch を main / root に設定
4. 発行されたURLへアクセス
